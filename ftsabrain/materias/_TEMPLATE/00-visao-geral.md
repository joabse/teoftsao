# Nome da Matéria — Visão Geral

> 🧩 **Modelo** — não usar como matéria real. Para criar uma nova matéria:
> 1. Copie esta pasta (`materias\_TEMPLATE\`) renomeando para o nome da disciplina (minúsculas, hífens).
> 2. Preencha o frontmatter (`materia`, `status`) e o título desta nota.
> 3. Registre a nova matéria no índice [[materias|MOC de Matérias]] e em `..\materias\` (ver README lá).
