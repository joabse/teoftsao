# 📒 Registro — Nome da Matéria

> 🧩 **Modelo** — não usar como matéria real. Para criar o registro de uma nova matéria:
> 1. Copie esta pasta (`memoria\materias\_TEMPLATE\`) renomeando para o nome da disciplina (minúsculas, hífens).
> 2. Preencha o frontmatter (`materia`) e o título desta nota.
> 3. Atualize a tag (`memoria/<nome>`) e o link para a visão geral da matéria no vault.
> Entradas em ordem cronológica decrescente (mais recente no topo), registradas pelo **ftsalider** após validar cada etapa.
